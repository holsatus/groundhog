# Icons

The icons are [Lucide](https://lucide.dev) icons (ISC license), saved under
their Lucide names: 24×24, `stroke="currentColor"`. The colour in the file
does not matter; the UI tints every icon to its theme.

To add one, save its SVG here and add a line to the `icons!` list in
`src/ui/icon.rs`. The file is embedded in the binary at compile time.
